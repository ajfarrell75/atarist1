Help & shortcuts
  • Mouse: click inside the screen to capture it (GEM cursor), Del to release it. Esc is sent to the ST.
  • Keyboard: routed to the IKBD (US layout). Keyboard joystick: arrows + right Ctrl = fire button (port 1).
  • Game floppies: "Mount A: + Reset" switches to a real TOS when needed (EmuTOS only boots system floppies) — TOS 2.06 on STE/Mega STE, TOS 1.0x on ST. Pick a ROM by hand to lock that choice.
  • Drag and drop: drop a .st / .msa / .dim / .stx image straight onto the screen to mount it in A: and reboot.
  • Machine & RAM: fixed when the machine is built → changing them reloads the page (URL parameters ?machine= and ?mem=, shareable).
  • Sound: browsers require a user gesture — click once inside the screen to unlock audio (YM2149 + STE DMA + drive noises).
